Connect Chrome to PopcornStash

Server

Sending

Chrome pauses each new download and hands its link to PopcornStash. Chrome's copy is cancelled only after PopcornStash starts fetching the file. If that fails, Chrome carries on as usual. Downloads from PopcornStash itself and from incognito windows stay in Chrome.

Some sites only let signed-in people download. With this on, each link you send carries the cookies Chrome holds for that link's site, and only that site, so PopcornStash can fetch the file as you.

The trade-off: those cookies can sign in as you on that site. PopcornStash keeps them in memory for the one download and never saves them, but anyone in control of the server could use them while it runs. Turn this on only for a server you run yourself. Chrome will ask to let the extension read cookies on all sites.

Privacy

  • The access key for your server stays on this computer, in Chrome's local extension storage. It is never synced to your Google account.
  • Links go only to your PopcornStash server. The extension sends nothing anywhere else.
  • Cookies travel only when the option above is on, and only the download site's own. Cookies for PopcornStash itself are never sent.
  • To remove this browser's access completely, open PopcornStash, Settings, Devices, and remove it there.
