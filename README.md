# PopcornStash

A secure, private library for family videos, photos and downloaded media. Part of the Popcorn series.

- Passkey-only access for the whole family
- Torrents that only ever travel through your VPN (NordVPN in two steps)
- Web links, a Chrome extension, Android share, browser uploads and an Inbox folder
- Automatic sorting into Movies, Shows, Home Videos and Photos
- Plays in any browser, transcoding only when needed

Work in progress. See [PRODUCT.md](PRODUCT.md) and [docs/architecture.md](docs/architecture.md).
